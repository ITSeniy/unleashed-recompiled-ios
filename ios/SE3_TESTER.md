# Тестовый билд для iPhone SE 3

Это экспериментальный Release-билд для arm64, минимальная версия iOS — 16.4.
Он проверен на обычном iPhone 15. Запуск и производительность на SE 3 пока не
проверены. В IPA включены исправления текстур для устройств без BC, полного
экрана, синхронизации кадров и чёрного экрана при запуске.

## Подпись

`UnleashedRecompiled-iOS-SE3-test-unsigned.ipa` нужно подписать своим сертификатом
и соответствующим provisioning profile. Наш профиль и подпись удалены.
Инструмент подписи должен выставить идентификаторы приложения и команды из
вашего профиля; при необходимости выберите свой уникальный bundle ID.

JIT не нужен: процессорный код игры скомпилирован заранее. Подключать отладчик
или активировать JIT для запуска не требуется. Специальные права отсутствуют:

- `com.apple.security.cs.allow-jit`;
- `com.apple.security.cs.allow-unsigned-executable-memory`;
- `com.apple.developer.kernel.increased-memory-limit`;
- `com.apple.developer.kernel.extended-virtual-addressing`.

`get-task-allow` в исходной подписи — стандартное право отладки Development-билда,
а не требование игры. Новый подписывающий инструмент выставляет права согласно
своему профилю. Для первого теста дополнительные права памяти не добавляйте.

Игра резервирует 4 ГиБ виртуальных адресов для гостевой памяти. Это не расход
4 ГиБ RAM. На iPhone 15 резервирование и игра работают без расширенных прав;
успех на SE 3 и его версии iOS ещё нужно проверить.

Apple различает [расширенное адресное пространство](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.developer.kernel.extended-virtual-addressing)
и [повышенный лимит памяти](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.developer.kernel.increased-memory-limit).
Повышенный лимит доступен лишь на некоторых моделях; его добавление не
гарантирует дополнительную память на SE 3.

## Данные игры

IPA не содержит полного набора игровых данных. После установки откройте
приложение один раз, затем закройте. Скопируйте свой установленный набор данных
Sonic Unleashed в `Documents/UnleashedRecomp` внутри контейнера приложения:

```text
Documents/UnleashedRecomp/
  game/
  update/
  patched/
```

Используйте согласованный набор оригинальной игры, обновления и `patched`,
который подходит этой версии рекомпиляции. На Mac папка Documents доступна
через файловый обмен приложением в Finder; также можно использовать файловый
обмен установщика IPA. Копируйте папку `UnleashedRecomp` целиком, сохраняя
вложенность. Полный проверенный набор занимает примерно 6,1 ГБ.

## Первый запуск и проверка

1. Начните с настроек по умолчанию: масштаб 0,5×, 30 FPS, Auto, VSync включён,
   без MSAA. Включите Metal HUD в настройках видео и перезапустите приложение.
2. Дойдите до уровня, поиграйте две минуты. Проверьте изображение, управление,
   FPS и расход памяти в HUD. Запускайте приложение обычным способом, без
   подключённого отладчика.
3. Если всё работает, попробуйте 60 FPS, масштаб 0,5×, Auto, VSync выключен.
   После перехода между 30 и 60 FPS обязательно перезапустите приложение:
   количество буферов Auto выбирается при запуске.
4. Передайте версию iOS, настройки, снимок HUD и наблюдения о вылетах/рывках.
   Если приложение вылетело, сохраните журнал
   `Documents/UnleashedRecomp/unleashedrecomp.log` и системный отчёт о вылете
   или JetsamEvent, если он появился в аналитике iOS. Это поможет отличить
   ошибку запуска, нехватку адресного пространства и превышение лимита RAM.

## Упаковка на стороне разработчика

Из корня репозитория после сборки Release:

```sh
python3 ios/package_ipa.py
```

Готовая IPA и JSON с контрольными суммами находятся в `out/ios/dist`.
Скрипт меняет только временную копию приложения, проверяет архив и удаление
подписи. Исходное приложение для тестов на iPhone 15 остаётся подписанным.
